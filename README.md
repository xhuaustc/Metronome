# 钢琴练习节拍器 · iOS

打开即用、节拍稳定、看得清听得懂的单功能节拍器。无账号、不联网、不收集数据。

需求与交互规范见 [PRD.md](PRD.md)。

---

## 快速开始

```bash
open PianoMetronome.xcodeproj      # Xcode 直接运行
```

或命令行构建到模拟器：

```bash
xcodebuild -project PianoMetronome.xcodeproj \
           -scheme PianoMetronome \
           -sdk iphonesimulator \
           -destination 'generic/platform=iOS Simulator' \
           build CODE_SIGNING_ALLOWED=NO
```

仅验证核心节拍数学（不依赖 Xcode 工程，秒级完成）：

```bash
swift test
```

若在受限环境里报 `sandbox-exec: sandbox_apply: Operation not permitted`，SwiftPM 的内部沙箱被外层拦截，改用：

```bash
swift test --disable-sandbox
```

真机运行需在 Xcode 里选择自己的开发者团队（`Signing & Capabilities`），Bundle ID 当前为 `com.mpan.pianometronome`。

## 外观与声音

外观、声音独立选择并分别保存在本机。默认是图标同款银白机身及清脆机械敲击声。

- 外观：银白、胡桃木、象牙白、曜石黑。主页机身区域左滑／右滑循环切换，旧机身沿手势方向滑出、新机身从另一侧滑入，过渡约 0.3 秒；不改变声音或练习进度。设置页保留完整外观选择。
- 声音：清脆机械敲击、木壳机械敲击、柔和机械敲击、紧致机械敲击。在设置的独立声音区域点选，停止时可按右侧按钮试听。播放中选择的声音随后续节拍生效，不叠加试听。
- 旧绑定主题自动迁移为原外观和原声音组合；已有独立音色偏好的旧数据保留其选择。

声音采用撞击瞬态、快速衰减的机身共振与带限接触噪声合成。首次使用显示滑动提示，成功切换后隐藏；配重上下拖动仍用于调速，底部操作区不响应外观滑动。

## 渐进提速练习

从主页开始按钮上方或设置页进入。默认关闭，方案默认为 **60 → 96 BPM，每 8 小节增加 4 BPM**。起始与目标均为 20–400，目标不低于起始；增量 1–40，间隔 1–32 小节。

- 预备拍不计入，完成指定数量的小节后在后续小节首拍提速，最终保持目标速度播放。
- 主页练习入口右侧开关可在停止时直接启用／关闭，保留上次方案；点击标题进入配置。播放中不可切换模式。
- 主页显示实际播放速度与阶段进度，可保持当前速度、继续自动提速或退回上一档并保持。点击立即显示待生效状态，等待期间禁用重复操作；实际听到生效小节后才确认状态。
- 停止／系统中断后清除运行进度，再次开始从起始速度重练；方案保留，不自动出声。
- 训练中锁定节奏参数，外观、声音和音量仍可独立调整。停止后选择收藏会切回普通节拍。
- 训练由音频采样时钟推进，不依赖界面刷新；已有前瞻音频不改写，因此手动控制在后续尚未排入的完整小节生效。

完整需求与验收规则见 [PRD §10](PRD.md#10-渐进提速练习与独立声音2026-11-04-增补)。

## 拍号、计拍与速度

支持 14 种拍号：2/4、3/4、4/4、3/8、6/8、9/8、12/8、2/2、3/2、6/4、5/4、7/4、5/8、7/8。主页保留四个常用项，「更多」打开完整拍号与计拍面板。

- 速度范围为 **20–400 BPM**，以页面显示的音符为准：2/2、3/2 按二分音符计拍；复拍子可选择按附点音符大拍或按谱面分母小拍计拍。
- 6/8、9/8、12/8 的大拍分别为每小节 2、3、4 拍，单位为附点四分音符；6/4 为每小节 2 大拍，单位为附点二分音符。可通过「启用每大拍三等分」加入小拍提示。
- 切换复拍子计拍单位时换算 BPM，尽量保持小节时长；整数取整或超出 20–400 时可能有变化。播放中计拍方式与换算速度一起在后续小节生效，已排音频不改动。
- 5 拍支持 2+3、3+2；7 拍支持 2+2+3、3+2+2、2+3+2 重音分组。
- 收藏同时保存计拍单位、分组与细分。旧设置和旧收藏缺少新字段时保持原来的小拍计速，不改变其 BPM。

## 常用节拍

主页固定显示，不支持整页上下滚动；机身根据剩余高度缩放，展开收藏夹后底部操作区仍完整可见。配重可上下拖动调速，上慢下快；机身仅保留四个参考速度数字。
点击底部「收藏当前」或空位可保存当前 BPM、拍号、计拍方式、分组、细分和重音，最多 5 组，自动保存在本机。点击收藏一键切换；调整参数后，展开收藏夹并长按要更新的记录，选择「用当前设置覆盖」可保留原位置更新，也可选择移除。满 5 组时仍可覆盖，重复设置不会写入其他收藏。外观、声音、音量、预备拍和屏幕常亮偏好不随收藏改变。播放中切换沿用现有节拍／小节边界生效规则。

底部操作区依次提供拍号、细分、常用节拍和全宽开始／停止按钮，拍号与细分可直接点选。「收藏当前」无需展开即可保存；收藏夹默认收起，展开选择后或点击空白处自动收起，不覆盖拍号与细分。主题、音量等低频设置统一从右上角齿轮进入。

开始后摆杆以左右各 18° 的摆幅按音频采样时钟左右摆动，每个主拍抵达交替端点；细分不会增加摆动次数，切换拍号和预备拍不会重置方向。停止后回到中央。开启系统「减弱动态效果」时关闭额外过渡动画，保留表示节拍的完整摆幅。

## 两条不能破坏的规则

**1. 时间只有一个来源：采样帧。**

`SchedulePlanner` 用 `anchorFrame + n × framesPerBeat` 一次乘法得出每一拍，不做累加，所以不存在浮点累积漂移。调度层每 100ms 把未来 1.0s 的拍点排进播放器；界面用 `CADisplayLink`/`TimelineView` 读播放头只读投影，永远不会反向驱动音频。

已验证：120 BPM 连跑 30 分钟共 3600 拍，最大偏差 < 1e-6 帧。

**2. 已排入的拍绝不重算。**

改 BPM 和音色在下一拍生效；改拍号、细分、重音在下一小节生效。因为已调度的 buffer 不动，"补响"和"叠音"在结构上不可能发生。

## 实现与 PRD 的偏差

- **路由切换**：PRD 要求淡出 120ms 后重建音频图继续播放。当前实现为"系统无缝接管，仅在引擎真的停止时复位到第一拍"。更保守，不会爆音，但极端情况下会断拍。
- **复拍子计拍**：已支持大拍与小拍切换；计拍单位和当前 BPM 均在页面标明。
