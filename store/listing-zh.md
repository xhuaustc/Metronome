## 描述（≤4000 字符）

```
知拍节拍器，陪你从慢练开始，稳稳跟上每一拍。

为钢琴练习打造，也适合吉他、小提琴等乐器的日常节奏训练。打开应用，调好速度，一键开始。清晰的拍点、随节拍摆动的机械摆针，让练习更直观。

【从慢练到目标速度】
设置起始速度和目标速度，按指定小节数自动提速。遇到难点时保持当前速度，或退回一档，准备好再继续。到达目标后保持播放，让你专注手上的练习。

【你需要的节奏，随手可调】
· 20–400 BPM，支持直接输入、加减按钮和拖动配重调速
· 14 种拍号，覆盖常用拍子、复拍子及 5 拍、7 拍
· 复拍子可按大拍或小拍计速，不规则拍子可选重音分组
· 二、三、四等分细分提示，配合重音练习节奏
· 可选一小节预备拍，给双手留好准备时间

【常练的节奏，一键找回】
最多收藏 5 组常用设置，保存速度、拍号、计拍方式、重音分组和细分。练不同曲目时快速切换，也可长按覆盖更新。

【看得清，也听得清】
大字号速度、清晰拍点与机械摆针，方便放在谱架上查看。四种外观与四种机械敲击音色独立选择，音色支持试听，找到适合自己的练习搭配。

【让练习少一点打断】
支持屏幕常亮、锁屏与后台播放。来电或系统音频中断时停止，之后由你手动重新开始。设置自动保存在本机，再次打开即可接着使用。

【简单，安心】
无广告、无内购、无需注册。完全离线运行，不收集个人数据，不申请麦克风权限。

从今天的一次慢练开始，把节拍练稳。
```

## 审核备注（App Review Information → Notes）

这一段很重要。后台播放是审核员最常追问的点，写清楚可以减少一轮往返。

```
本应用是一个节拍器。开启播放后，即使锁屏或切到其它应用，节拍声也会继续，
这是钢琴练习的实际需要（练习时需要看谱，屏幕会锁）。因此启用了 UIBackgroundModes = audio。

复现方式：
1. 打开应用，点击首页「开始」按钮开始播放，会听到稳定的节拍声。
2. 按侧边电源键锁屏，节拍声继续，间隔不变。
3. 重新解锁回到应用，查看界面拍点和小节。

应用完全离线运行，无账号、无网络请求、无内购、无广告。
拍号选择器支持 14 种拍号；复拍子可选择大拍或小拍计速。

本次构建新增渐进提速练习：在首页进入「渐进提速」，启用并配置起始速度、目标速度、增量和每档小节数，返回首页后开始。播放中可保持、继续或退回一档；到达目标后保持。训练在音频时钟上推进，锁屏后仍可继续。

设置中的外观和声音分别保存，左右滑动首页机身仅切换外观。声音可逐项试听，无需开始播放。
```

## 构建 4 更新说明（2026-11-04）

- 新增主页练习开关，改进保持／继续／退档的待生效反馈与防重复点击。
- 新增渐进提速练习：按小节自动提速，支持保持、继续、退回一档，到达目标后保持。
- 外观和声音可分别设置，新增独立音色试听，优化机械敲击音。
- 支持 20–400 BPM、14 种拍号、复拍子计速与不规则拍号分组。
- 收藏支持覆盖更新，展开后点击空白处收起。
- 首页固定布局，优化左右切换外观的过渡与摆针幅度。

首次上架仍使用版本 1.0；以上内容用于审核备注和发布记录，首次版本不强填「此版本新增内容」。
